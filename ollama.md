## To start the ollama server

```
ollama serve
```

## To pull the model

```
ollama pull gemma:latest
```

## To run the model

```
ollama run gemma:latest
```

## To list the models

```
ollama list
``` 

## To delete the model

```
ollama rm gemma:latest
```
