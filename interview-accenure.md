## Transfermer
>> A Transformer is a neural-network architecture introduced for processing sequential data efficiently. Its key mechanism is self-attention, which allows the model to understand relationships between different tokens in the context. Modern LLMs such as GPT are based on the Transformer architecture.

## Embeddings
>> An embedding is a numerical vector representation of data, usually text, that captures its semantic meaning. Embeddings allow us to compare the similarity between pieces of information and are commonly used in semantic search, vector databases, and RAG systems.

## Hallucination
>> Hallucination occurs when an AI model generates information that sounds plausible but is incorrect, unsupported, or fabricated.

## How can we reduce hallucinations?
>> Common techniques:
* RAG
* Better prompts
* Grounding responses in trusted data
* Tool/function calling
* Fine-tuning for specific behavior
* Validation
* Asking the model to cite sources
* Confidence/uncertainty handling

## Fine Tuning
- It is process to perform training on pre-trained model with your own dataset so that it beacome better for the specific task.

## What is prompt engineering?
- It means how we can guide the AI to generate the desire output.
- Common techniques to use prompts
    * zero-shot prompt
    * one-shot prompt
    * few-shot prompt
